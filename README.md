# Isaac Veliz — Professional Portfolio

Portafolio construido con Next.js App Router, React, TypeScript strict y Tailwind CSS v4.

## Requisitos

- Node.js 20.9+
- npm

## Desarrollo

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Verificación

```bash
npm run lint
npm run typecheck
npm run build
```
